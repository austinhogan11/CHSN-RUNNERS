# Runner Releases

This directory records the behavior of shipped Runner releases.

- [V1.1](V1.1.md) adds native iOS support on the shared Runner API and user data.
- [V1](V1.md) describes Runner V1 as it shipped in September 2026.

Release records are historical snapshots. `V1.md` and `V1.1.md` should not be
rewritten to describe later product behavior. Future releases should receive
their own files, such as `V1.2.md`, `V2.md`, and later versions, so that each
shipped state remains reviewable.
